# P6 第二階段：新基礎臉型試作

## 目標
原版男、女角色保留。男生第二款方向：較俐落、明顯下顎、眼睛比例較成熟；女生第二款方向：典雅橢圓臉、較收斂的下顎與不同眼形。保留相同髮型、照明、上半身位置與圓框。

## 本輪實作
- 以目前十二個已發布來源為基礎，獨立輸出試作的 512×512 透明無損 WebP 和同座標 RGB 材料遮罩；保留原檔。
- 使用連續、可逆的二維幾何映射，避免將不同臉部圖塊硬貼在既有圖上。眼鏡區為固定仿射映射，後續獨立鏡框採逆向變換，衣領以下為精確恆等映射。
- CI 檢查來源 SHA256、映射 Jacobian、固定區域、材料通道不重疊、可辨識的臉部像素差異、無損編碼及實際比較圖（256px / 80px）。
- 此為 source-derived 2D 臉型試作，不是獨立建模的第二角色，也不等於新美術已獲驗收。臉型是否足夠有差異、是否自然、眼鏡能否精確對位，需看實際畫面。

## 上線閘門
1. 審視 12 組實際候選圖；若只像原角色變形，拒絕此方向，改製作真正獨立的新角色素材。
2. 驗收後才將候選素材及 SHA 登記為正式可選臉型，避免未存在的素材路徑。以顯式 faceVariant（原版缺省）保存，不啟用既有 dormant portraitFamily。原使用者外觀不變。
3. 共用 renderer 以同一新臉型來源和同座標遮罩繪製；衣服、頭部裁切、髮型、背景、動物不變。眼鏡圖層應用相同眼區座標，測試無鏡、原款、圓框、方框。
4. 新增選擇、持久化、顏色通道、輪廓和眼鏡對位測試，保留 P5/P6 既有測試。正式與休閒服裝都要檢查。
5. 實機註冊及個人設定選擇、切換、儲存重開，通過才合併。Draft 不改 main。

本輪只進行離線素材試作及驗證，尚未開放新臉型選項。沒有資料庫或部署設定變更。
