# 管理員任務到點震動測試

- 獨立開關 `ENABLE_ADMIN_TIMELINE_VIBRATION_TEST`，只在 production 且已配置既有 Web Push 金鑰和 dispatcher secret 時有效，不開啟正式提醒旗標。
- 管理員使用原震動提醒設定，允許 iPhone 主畫面 Web App 通知後選擇堂次進入流程。伺服器依當日台北時間讀取該堂啟用的共用流程，去重並略過第一區塊。已過時間不補發。切離流程會嘗試停止測試綁定，正式有效報到優先；測試至當日午夜或最多十二小時。角色撤銷、登入失效、關閉開關及離開當日皆阻止後續推播。
- 不建立報到、排班、任務完成紀錄，不修改正式週末堂次限制。推播內容標為管理員測試。iPhone 實際震動取決於系統通知、專注模式和觸覺設定。
- 正式 migration 檔名由 CI 內 Supabase CLI 產生（20261126131612），已移除暫存生成步驟。正式資料庫 migration 必須先經核准及驗證，檢查現有 cron/secret/正式旗標配置，之後才可啟用管理員測試旗標。預覽環境不寫正式資料庫。
- 實機：平日選六晚崇/主一堂/主二堂，流程頁顯示測試已啟用；在前景、鎖屏分別跨真實任務時間；同分鐘只一則；換堂/關閉震動/登出後不再收到舊堂提醒。確認普通同工原權限不變。沒有真機結果不可宣稱震動通過。
