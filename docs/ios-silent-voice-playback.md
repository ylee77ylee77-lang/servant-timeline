# iPhone 靜音模式語音相容性

## 變更範圍
在支援 Audio Session API 的 Apple 行動裝置，語音助理的播放操作開始前嘗試將自動音訊模式切換為 playback，操作結束、取消或失敗時釋放；不更改其他明確音訊模式。涵蓋啟動確認、正式提醒佇列、管理員試聽、定時測試及回到前景的恢復。靜默解鎖和預載不切換模式。通話、語音留言及語音辨識在要求麥克風前保留 auto 路由，防止播放模式覆蓋錄音。
不增加設定欄位、音量控制、背景計時或通知。其他裝置維持原有播放器；API 不支援或拒絕時無中斷回退。

## iPhone 驗收（使用此 PR 預覽）
1. 正常音量、非靜音：在原本頁首語音助理開關 OFF → ON，應聽到原有啟動確認。
2. 切換 iPhone 靜音模式，媒體音量仍約 40%，保持頁面前景，OFF → ON；聽見確認音和適用的任務播報。
3. 使用既有管理員即時語音測試的快速測試，保持畫面前景，提前與準點兩段都聽得到，文字與時間符合原設定。
4. 插入耳機或藍牙耳機、外部 App 返回流程、開關取消、男／女聲切換，確認原有功能不退化。
5. 使用問助理、語音留言及 App 內通話，確認麥克風和音訊輸出沒有因播放模式失效。
6. 媒體音量降為零應仍無聲；本功能不調整系統音量，不視 API 播放成功為實際聽見。

## 限制
Audio Session API 並非所有瀏覽器支援。playback 可能暫停其他媒體；故限制在語音播放操作期間並儘快還原。iOS 靜音模式相容性需要真機驗收，不能從 CI 斷定。鎖屏連續背景語音、通知聲音或震動不在本次範圍。
